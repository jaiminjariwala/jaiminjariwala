# Retro README assets

The active `welcome.png`, `guestbook.svg`, and `marquee.svg` assets originated
from [BrunnerLivio's profile images](https://github.com/BrunnerLivio/brunnerlivio/tree/master/images)
at the repository owner's request.

The guestbook label uses native SVG text and a centered pulse to avoid Safari
rendering artifacts from scaling embedded HTML. Its colors and the surrounding
README link are preserved.

The upstream repository does not expose a license through GitHub's license API.
Attribution does not establish reuse permission.

The personalized `../personal-note.svg` follows the reference's font stack,
lime-green text, and blinking language treatment.
